Travel website project

Project overview

One travel concept, multiple destinations.

The student website organizes travel-related information for visitors considering a European trip. Its navigation includes England, France, Germany, Ireland, Italy, Scotland, Spain, and Sweden, alongside a contact page.

Information architecture

Separate destination pages create an understandable structure for visitors browsing different European countries.

Editorial content

The homepage introduces trip planning, travel agents, lodging, transport, activities, and destination knowledge.

Student project context

This portfolio entry presents the original educational website, not a functioning travel agency or an independently completed redesign.
