Travel website project

Project overview

One travel concept, multiple destinations.

The student website organizes travel-related information for visitors considering a European trip. Its navigation includes England, France, Germany, Ireland, Italy, Scotland, Spain, and Sweden, alongside a contact page.

Information architecture

Separate destination pages create an understandable structure for visitors browsing different European countries.

Editorial content

The homepage introduces trip planning, travel agents, lodging, transport, activities, and destination knowledge.

Bootstrap contact form

The dedicated contact page combines a responsive two-column form layout, text inputs, select menus, date pickers and a comments field to collect travel preferences in an organized way.

Featured design element · Bootstrap

A structured travel inquiry form.

The contact page is a key part of this student project. Built with Bootstrap's grid and form styling, it uses paired fields to make a detailed travel inquiry easier to scan, with a wider comments area and prominent submit action. Form elements and design choices

Bootstrap grid

Paired fields are organized in two columns on larger screens to make good use of the available width.

Text inputs

First and last name, telephone, email address, and departure airport collect essential contact and trip details.

Select menus

Age, student status, preferred country, and travel interests are gathered through consistent dropdown controls.

Date controls

Departure and return date fields allow travellers to specify their preferred schedule.

Comments and submission

A full-width multiline comments area provides room for additional details, followed by a clearly visible Submit button.
